# 🛠️ **Hướng dẫn cài đặt** 🛠️
`Giải nén` → Giải nén nếu tệp tin là định dạng đóng gói (zip, gz,...).
`Kiểm tra thư viện` → Kiểm tra file package.json phần dependependencies.
`Cài đặt nhanh thư viện` → Chạy thêm terminal ngay tại đồ án: npm install --force
`Khởi chạy dự án` → Khởi chạy dự án: npm start

## Sử dụng gọi các gói (module)

### 1️⃣ **Dấu trang** 🛠️
📌 `./` → Thư mục hiện tại (cùng thư mục với tệp đang chạy).
📌 `../` → Thư mục cha (cấp trên của thư mục hiện tại).

### 2️⃣ **Import gói** 🛠️
📌 `JavaScript` là một trong những ngôn ngữ yêu cầu khi import bất kì 1 gói nào tự build phải xác định cấp cùng với thư mục gọi gói
